## Description

- Wire clarification-respond through the a2a client (answers keyed by question id on the new verb) with a verb refusal treated as a value - the card shows failure and never collapses.
- On success, record the C8 recap into a dedicated view store keyed by run and request id, rendered by the transcript independently of the pending disclosure, cleared only when the bound run genuinely changes.

## Outcome

## Notes
